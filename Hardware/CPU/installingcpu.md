## Installing a CPU (Safe Procedure)

When installing a CPU, it is important to follow proper safety and handling practices to avoid damage.

---

## 1. ESD Protection

Before starting, use one of the following:
- Anti-static wrist strap  
- Anti-static mat  

This helps prevent **ESD (Electrostatic Discharge)**, which can damage electronic components.

---

## 2. Prepare the Motherboard

- Ensure the motherboard is accessible and properly positioned  
- Avoid touching sensitive areas, especially the socket pins  

**Important:**  
Do not touch the pins inside the CPU socket.

---

## 3. Align the CPU

In this example (AMD processor):

- Locate the alignment mark (usually a small triangle) on the CPU  
- Match it with the corresponding mark on the motherboard socket  

Proper alignment is critical. Never force the CPU into place.

---

## 4. Install the CPU

- Gently place the CPU into the socket  
- It should fit naturally without pressure  
- Double-check alignment before proceeding  

---

## 5. Lock the CPU (ZIF Mechanism)

- Lower the ZIF (Zero Insertion Force) lever  
- Secure it in place to lock the CPU  

---

## 6. Final Check

- Ensure the CPU is properly seated  
- Confirm the socket is fully locked  

At this point, the CPU is installed, and you can proceed with the next steps (such as applying thermal paste and installing the cooler).

---

## Summary

- Use ESD protection  
- Do not touch socket pins  
- Align CPU correctly  
- Do not apply force  
- Lock using ZIF mechanism  

Proper installation ensures system stability and prevents hardware damage.
