## Case 2: No Display After CPU Installation

### Problem
After installing a new CPU, the system powered on but showed no display.

### Analysis
- Fans and lights were working  
- No video output  
- RAM and GPU tested and working  
- CPU removed for inspection  

### Action Taken
- Verified CPU alignment with socket  
- Identified slight misalignment during installation  
- Reinstalled CPU correctly  
- Locked ZIF mechanism securely  

### Result
- System booted normally  
- Video output restored  

### Conclusion
The issue was caused by incorrect CPU installation (misalignment in socket).
