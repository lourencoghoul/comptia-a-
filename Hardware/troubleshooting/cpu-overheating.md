## Case 1: CPU Overheating and System Shutdown

### Problem
User reports that the computer shuts down after a few minutes of use, especially during heavy tasks.

### Analysis
- System powered on normally  
- No error messages  
- Checked CPU temperature in BIOS: above 90°C  
- Fan was spinning, but airflow seemed weak  

### Action Taken
- Removed the CPU cooler  
- Cleaned dust from heatsink and fan  
- Reapplied thermal paste  
- Reinstalled the cooler properly  

### Result
- CPU temperature reduced to ~60–70°C under load  
- No more random shutdowns  

### Conclusion
The issue was caused by overheating due to poor cooling contact and dust buildup.
